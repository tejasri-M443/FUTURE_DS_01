
# SalesScope — Business Sales Performance Analytics

**Internship:** Future Interns  
**Domain:** Data Science & Analytics  
**Task:** FUTURE_DS_01

## 1. Project Overview

SalesScope is an interactive business sales analytics dashboard developed to analyze sales data and understand business performance.

The dashboard helps identify sales trends, profitable products, category performance, and regional sales. It converts raw business data into visual charts and key performance indicators (KPIs) to support better business decisions.

## 2. Project Objectives

- Analyze overall sales and profit.
- Understand monthly sales trends.
- Identify top-selling products.
- Compare sales across product categories.
- Analyze sales performance across regions.
- Generate useful business insights and recommendations.

## 3. Technologies Used

- **HTML5:** Creates the dashboard structure.
- **CSS3:** Provides styling, responsive design, animations, and 3D-style background effects.
- **JavaScript:** Processes the dataset and updates dashboard metrics.
- **Chart.js:** Displays interactive charts.
- **Papa Parse:** Reads and processes CSV files.
- **Visual Studio Code:** Used to develop the project.

## 4. Dataset Description

The project uses a Superstore sales dataset containing information about customer orders, products, sales, quantities, and profits.

The dashboard recognizes common columns such as:

| Column | Meaning |
|---|---|
| Order Date | The date when an order was placed |
| Order ID | A unique identifier for an order |
| Region | The geographical region where the order was recorded |
| Category | The main type of product sold |
| Product Name | The name of the product |
| Quantity | The number of units sold |
| Sales | The revenue generated from a sale |
| Profit | The profit or loss recorded for a sale |

**Note:** The exact column names depend on the CSV dataset being used. The dashboard must be able to recognize the relevant columns for its calculations to work correctly.

## 6. Key Performance Indicators

### Total Sales
The sum of all recorded sales amounts. It represents the revenue generated by the business.

### Total Profit
The sum of all recorded profit values. A negative value indicates a loss.

### Total Orders
The number of unique orders recorded in the dataset, based on Order ID.

### Total Units Sold
The total quantity of products sold.

### Average Order Value
Calculated by dividing total sales by the number of unique orders.

**Formula:**

Average Order Value = Total Sales / Total Orders

## 9. How to Run the Project

1. Install Visual Studio Code.
2. Open the `FUTURE_DS_01` folder in VS Code.
3. Place `Superstore_Database.csv` in the same folder as `index.html`.
4. Install the Live Server extension in VS Code if needed.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. Wait for the dashboard to load the dataset.

If the dataset does not load automatically, use the **Load your CSV** option in the dashboard and select the CSV file.

An internet connection is required for external libraries and fonts loaded through CDNs.
